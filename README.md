# PipeScope
PipeScope: Linux Pipeline Explorer

## To run:

PipeScope only works on Linux or WSL, attempting to use it on Windows will cause errors.

## Run from npm:
Run `npm install -g pipescope`, then navigate to your chosen directory and run `pipescope`

## Run from source:
Clone this repository locally.

Run `npm install` to install npm packages

`node server.js` to launch PipeScope from this directory

To run from any directory, run `npm link`, then navigate to your chosen directory and run `pipescope`
